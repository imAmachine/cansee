# Vost Clean

Минималистичное расширение Manifest V3 для Chromium-браузеров (включая Helium), которое заменяет интерфейс animevost.org и поддерживаемых зеркал.

## Установка в Helium

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Выберите «Загрузить распакованное расширение» и укажите эту папку.

## Текущая версия

`0.12.0` — отполирована страница тайтла: метаданные, плеер, панель серий и управляющие кнопки.

## Ограничения

Расширение использует только ссылки, которые сам сайт отдаёт браузеру. HLS/DRM и недоступные пользователю потоки не обходятся.

Загрузками после отправки управляет браузер: их состояние и ошибки доступны на `chrome://downloads`. Эта версия не ограничивает количество одновременно выполняемых загрузок. Ссылки могут истечь или требовать дополнительных условий; просмотр и скачивание в Helium ещё необходимо проверить на практике. Страницы сайта или формат плеера могут измениться.
