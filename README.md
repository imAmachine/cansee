# CanSee

Расширение Manifest V3 для Chromium-браузеров (включая Helium) с модулями оформления сайтов. Первый модуль — Vost Clean для animevost.org и поддерживаемых зеркал.

В версии 1.1 модуль включён по умолчанию. Нажмите на иконку расширения, чтобы включить или выключить оформление для текущей вкладки. После изменения вкладка перезагружается; другие уже открытые вкладки применят настройку при следующей загрузке.

## Установка в Helium

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Выберите «Загрузить распакованное расширение» и укажите эту папку.

## Текущая версия

`1.3.1` — поддержка нового плеера animevost: ссылки на видео и загрузки собираются из страницы плеера, запасных зеркал и `getlink.php`, а плеер переключается на следующее зеркало при ошибке воспроизведения. Оформление больше не отказывается запускаться на медленных загрузках, из-за которых иногда требовалось обновление страницы.

## Первый релиз 1.0.0

Первый стабильный релиз Vost Clean: каталог с ленивой подгрузкой, лента последних обновлений с группировкой по датам и кэшем, поиск, просмотр и скачивание доступных серий, сохранение последней выбранной серии, темы и режимы отображения.

## Проверки

```sh
node --test tests/*.test.cjs
node --check modules/vost-clean/content.js
node --check modules/vost-clean/media.js
```

Проверены в браузере: поиск `naruto`, каталог с догрузкой 20 → 40 карточек, расписание с бейджем текущего дня, темы и виды, лента последних обновлений. Тайтлы 4066, 3752 (48 серий), 506 (25 серий), ONA 4085, фильм с единственной серией «Фильм» и зеркало `v14.vost.pw` воспроизводят 720p через `res.trn.su`/`miniru.trn.su`; `hd.miskuzi.link` в проверке зависал на медиапотоке, поэтому зеркало выбирается по реальной загрузке метаданных. Скачивание проверено для серии с тайтла и из ленты: файлы 156 МБ и 197 МБ открылись как корректный MP4. «Скачать всё» вживую не запускалось (объём загрузки), его пакетная логика покрыта тестами. Тесты background и разбора ссылок используют сохранённые страницы сайта и не скачивают файлы.

## Ограничения

Расширение использует только ссылки, которые сам сайт отдаёт браузеру. HLS/DRM и недоступные пользователю потоки не обходятся.

Общее ядро находится в `core/`, код Vost Clean — в `modules/vost-clean/`. Метаданные встроенного модуля регистрируются через `core/registry.js`: требуются уникальный `id`, `name`, `description` и функция `matches(url)`. Для добавления модуля нужно подключить его регистрацию в `popup.html`, объявить адреса, скрипты и ресурсы в `manifest.json`, использовать `ModuleState.readEnabled(id)` перед изменением страницы и проверить необходимые разрешения. Адреса в манифесте и `matches` должны совпадать. Это внутренний контракт, а не API установки сторонних модулей.

Логика скачивания пока относится только к Vost Clean и находится в `modules/vost-clean/background.js`; новый модуль не должен ослаблять её проверки адресов. При чтении настройки исходная страница может ненадолго появиться до оформления; при ошибке чтения или запуска остаётся оригинальный сайт. Для работы popup расширение получает временный доступ к активной вкладке при нажатии на его иконку.

Загрузками после отправки управляет браузер: их состояние и ошибки доступны на `chrome://downloads`. Эта версия не ограничивает количество одновременно выполняемых загрузок. Скачивание разрешено только с зеркал сайта (`roomfish.ru`, `trn.su`, `miskuzi.link`, `tigerlips.org`). Ссылки могут истечь или требовать дополнительных условий; просмотр и скачивание в Helium ещё необходимо проверить на практике. Страницы сайта или формат плеера могут измениться.
